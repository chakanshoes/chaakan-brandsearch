저장 설정

저장하기를 누르면 GitHub 저장소 의 데이터 파일이 갱신돼요. 저장하는 사람만 이 PC에서 한 번 GitHub 토큰을 넣으면 돼요. 보기만 하는 사람은 필요 없어요. 토큰은 이 브라우저에만 보관되고 다른 곳으로 보내지지 않아요.

  1. GitHub 토큰 만들기 페이지 ↗를 엽니다 (저장소에 쓰기 권한이 있는 계정으로 로그인).
  2. Repository access에서 Only select repositories → 이 저장소만 고릅니다.
  3. Permissions → Repository permissions → Contents: Read and write로 설정합니다.
